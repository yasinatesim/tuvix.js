# Prompt Enhancer

Builds a BRAID reasoning graph (Mermaid `flowchart TD`) for Bug, Feature, Refactor and Critical requests. Trivial edits and questions skip it. `SKILL.md` holds the node vocabulary, the four mandatory Check nodes, the escalation budget and two tuvix examples.

## Reference

- Armağan Amcalar and Eyup Cinar, [BRAID: Bounded Reasoning for Autonomous Inference and Decisions](https://arxiv.org/abs/2512.15959), arXiv 2512.15959, 2025.

## Usage

```markdown
/prompt-enhancer [the request or conversation]
```
